# Свадьба без паники 💍

Телеграм-бот для подготовки к свадьбе с чек-листом, бюджетом и управлением гостями.

## Функционал

✅ Чек-лист задач с автонапоминаниями (14/3/1 день до дедлайна)  
✅ Трекер бюджета с прогресс-баром и защитой от перерасхода  
✅ Управление гостями (+1, подтверждения, красивые приглашения в 1 клик)  
✅ Ежедневная мотивация и Книга воспоминаний  
✅ Экспорт данных в PDF с поддержкой кириллицы  
✅ Совместный доступ для пары (приглашение партнёра)  

## Запуск

1. Создайте виртуальное окружение: python -m venv venv
2. Активируйте его: env\Scripts\activate
3. Установите зависимости: pip install -r requirements.txt
4. Создайте .env с токеном бота: BOT_TOKEN=ваш_токен
5. Запустите: python bot.py
